# Lista de Tarefas

Projeto do Desafio 3 da Imersão da Alura com o Google. É uma lista de tarefas simples feita com HTML, CSS e JavaScript, criada com a ajuda do Google Antigravity.

## O que ela faz

- Adiciona tarefas
- Marca tarefas como concluídas
- Remove tarefas
- Mostra o total de tarefas e quantas já foram concluídas
- Guarda as tarefas no navegador, então elas continuam lá depois de recarregar a página

As tarefas concluídas ficam com o texto riscado e fundo verde, e vão para o final da lista.

## Como rodar

Baixe os arquivos e abra o `index.html` no navegador. Não precisa instalar nada.

## Arquivos

- `index.html`: estrutura da página
- `style.css`: visual
- `script.js`: lógica (adicionar, concluir, remover e salvar)

## Sobre o desenvolvimento

Pedi ao Antigravity para criar a base do app, depois pedi a melhoria visual das tarefas concluídas e por fim a execução dos testes. Nos testes ele corrigiu um problema no ID das tarefas, que podia se repetir se duas fossem criadas no mesmo instante.
